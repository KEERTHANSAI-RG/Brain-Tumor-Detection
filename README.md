# Brain Tumor MRI Classification Using Deep Learning

## Overview

This project is an AI-powered Brain Tumor MRI Classification application built using Python and Deep Learning.

It uses a trained **ResNet18 Convolutional Neural Network (CNN)** to classify brain MRI images into four categories:

- Glioma
- Meningioma
- No Tumor
- Pituitary

The application also integrates **Grad-CAM (Gradient-weighted Class Activation Mapping)** to generate heatmaps highlighting image regions that influenced the model's prediction.

## Key Features

- Brain MRI image classification into four categories.
- ResNet18-based deep learning model.
- Grad-CAM heatmap visualization.
- Original MRI and heatmap overlay.
- Confidence score for predictions.
- Streamlit-based interactive web application.
- Input validation to reject unsupported or invalid images.
- Model evaluation using precision, recall, F1-score, and a confusion matrix.

## Dataset

The project uses the Brain Tumor MRI Dataset by Masoud Nickparvar from Kaggle.

The dataset contains four classes:

1. Glioma
2. Meningioma
3. No Tumor
4. Pituitary

The dataset is organized into separate Training and Testing directories.

## Grad-CAM Explainability

Grad-CAM helps visualize the image regions that contributed to a model prediction.

- Red and warmer regions indicate greater influence.
- Blue regions indicate lower influence.
- The heatmap overlay combines the original MRI image with the activation map.

## Running the Project Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate into the project

```bash
cd brain-tumor-detection
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment (Windows)

```bash
venv\Scripts\activate
```

### 5. Install the required dependencies

```bash
pip install torch torchvision streamlit numpy matplotlib scikit-learn pillow opencv-python
```

### 6. Train the model (optional)

```bash
python src/train_model.py
```

### 7. Launch the application

```bash
python -m streamlit run app/app.py
```

Open the local URL displayed in your terminal to use the application.

## Limitations

This project is an educational and research demonstration. It is not a medical diagnostic system.

Predictions may be incorrect, and Grad-CAM visualizations do not establish the presence or location of a tumor. The application must not be used for medical diagnosis or treatment decisions.
